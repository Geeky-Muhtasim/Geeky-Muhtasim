# Fonts

The profile cards embed subsets of two typefaces, both under the SIL Open Font License 1.1:

- **IBM Plex Mono** (Regular, Medium): [OFL-ibm-plex-mono.txt](OFL-ibm-plex-mono.txt). Also in `scripts/fonts/` for the arena card.
- **Shippori Mincho B1** (Medium, Latin): [OFL-shippori-mincho-b1.txt](OFL-shippori-mincho-b1.txt).
